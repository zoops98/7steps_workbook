지문 암기와 동사 훈련 중심의 내신 워크북을 자동 생성합니다

1 Gemini API 키

키는 이 브라우저의 localStorage에만 저장되며 외부로 전송되지 않습니다. (Google Gemini 서버 호출 제외)

2 교재 정보

학원정보는 학습지 상단과 하단에 표시됩니다. 비워 두면 표시하지 않습니다.

3 지문 입력 — 본문을 나눠서 여러 개 입력할 수 있습니다 (본문 1, 본문 2, …)

영어 지문만 붙여넣으면 한국어 해석은 자동 생성됩니다. 교과서 해석을 그대로 쓰고 싶다면 해석 칸에 문장 순서대로 붙여넣으세요.
